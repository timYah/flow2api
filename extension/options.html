Flow2API Captcha Worker

此扩展在当前已登录的 Chrome Flow 项目页内完成 reCAPTCHA 和图片生成请求提交。Flow2API Python 服务仍负责参考图上传、结果处理和 API 响应。

使用前请先在 chrome://extensions 开启“开发者模式”，选择“加载已解压的扩展程序”，加载仓库中的 extension/ 目录。

需要绑定指定账号时，在管理台对应 Token 的“扩展路由键”中填写相同值；每个 Chrome 实例建议使用不同值。留空表示使用未指定路由的连接。
同时在 Chrome 中打开标签页执行 Flow 请求的并发上限。多场景批量生成或局域网机器推荐 2-4。
本机服务通常填写 ws://127.0.0.1:8000/captcha_ws；远程部署时替换为可访问的 ws:// 或 wss:// 地址。
保存后扩展后台会自动连接并重连 WebSocket。扩展不需要配置 Token 同步插件的连接地址或连接 Token。
